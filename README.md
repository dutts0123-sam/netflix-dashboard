# Netflix Dashboard

## Project Overview
An interactive dashboard developed using Python to explore and visualize Netflix content data.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Features
- Interactive dashboard for exploring Netflix data
- Data processing using Pandas
- Charts and visualizations using Plotly
- User-friendly interface built with Streamlit

## Installation

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command in the project folder:

```bash
streamlit run main.py
```

## Dataset
The project uses `netflix_data.csv` for data exploration and visualization.
